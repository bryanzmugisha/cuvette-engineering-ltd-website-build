# Cuvette Engineering (U) Ltd - Official Website

Professional static website for **Cuvette Engineering (U) Ltd**, a premier construction, infrastructure, and engineering services company in Uganda. Founded in 2019, we deliver high-quality, sustainable, and innovative building solutions across residential, commercial, industrial, and infrastructure projects.

The website showcases our:
- Company profile & values
- Mission, vision, and core strengths
- Comprehensive service offerings (construction, fiber optic networks, maintenance, CCTV/security, electro-mechanical, etc.)
- Key projects & portfolio gallery
- Contact information & call-to-action

## About the Project

This is the official online presence for **Cuvette Engineering (U) Ltd** – built as a clean, fast, responsive static site. It reflects our commitment to excellence, integrity, safety, innovation, and sustainability.

The design draws inspiration from our company profile (PDF), featuring:
- Red & black brand colors
- Professional typography & icons (Font Awesome)
- Mobile-friendly navigation with dropdowns
- Sections for About, Services, Our Works, and Contact

## Features

- Responsive layout (mobile, tablet, desktop)
- Sticky navbar with active link highlighting
- Hero banner with overlay text
- Grid-based sections (Why Choose Us, Services, Projects teaser)
- Contact form placeholder (expandable with Formspree/Netlify Forms)
- SEO-friendly meta tags & favicon setup
- Smooth hover effects & transitions

## Technologies Used

- **HTML5** – Semantic structure
- **CSS3** – Custom styling with variables, flexbox/grid, responsive media queries
- **JavaScript** – Mobile menu toggle & basic interactivity (cuvette.js)
- **Font Awesome** – Icons
- **Google Fonts** – Montserrat (modern & professional)
- No frameworks/build tools required (pure vanilla for simplicity & speed)
